# Спецификация деревьев

## Назначение

Деревья хранят элементы в порядке ключей и поддерживают поиск, вставку и удаление.

| Тип | Содержимое | Балансировка |
|---|---|---|
| `BinaryTree<Key, Data>` | Уникальные ключи и связанные с ними значения | Отсутствует |
| `RedBlackTree<Key, Data>` | Уникальные ключи и связанные с ними значения | Красно-чёрная |
| `Map<Key, Data>` | Псевдоним `RedBlackTree<Key, Data>` | Красно-чёрная |

`RedBlackTree` использует защищённое наследование от `BinaryTree` и явно открывает операции контейнера. Публичного преобразования к `BinaryTree` нет.

## Общие свойства

- Все ключи левого поддерева меньше ключа узла, правого — больше.
- Один ключ соответствует одному элементу. Повторная вставка ничего не меняет.
- Тип ключа задаёт согласованный линейный порядок. Операторы сравнения должны давать совместимые результаты.
- Дерево владеет своими узлами и освобождает их при уничтожении.
- Порядок значений `Data` на расположение элементов не влияет.

Ключи и значения в `BinaryTree` и `RedBlackTree` должны допускать копирование. Остальные требования зависят от операции: например, `replace` требует присваивания значения, а `print` — вывода ключа в поток. Для `range` также используется сравнение `>=`.

## BinaryTree

### Создание и владение

Пустой конструктор создаёт дерево размера 0. Конструктор с ключом создаёт один элемент со значением `Data()`, конструктор с ключом и значением — один элемент с переданными данными.

Копирование создаёт отдельные узлы с теми же ключами, значениями и связями. Копирующее присваивание заменяет содержимое получателя после создания полной копии. Оба вида самоприсваивания сохраняют дерево.

Перемещение передаёт элементы другому дереву и оставляет исходное дерево пустым. Перемещающее присваивание сначала освобождает прежние элементы получателя.

### Операции

| Метод | Результат |
|---|---|
| `insert(key, data)` | Добавляет пару, если ключ отсутствует. Существующее значение не перезаписывает |
| `remove(key)` | Удаляет элемент с указанным ключом |
| `replace(key, data)` | Меняет значение существующего элемента, сохраняя ключ |
| `at(key)` | Возвращает ссылку на значение. Для константного дерева ссылка константная |
| `containsKey(key)` | Проверяет наличие ключа |
| `size()` | Возвращает количество элементов |
| `get_root()` | Возвращает копию значения корня |
| `min()`, `max()` | Возвращают копию значения при минимальном или максимальном ключе |
| `entries()` | Возвращает `Array<std::pair<Key, Data>>` по возрастанию ключей |
| `keys()` | Возвращает `Array<Key>` по возрастанию |
| `range(first, last)` | Возвращает пары с ключами из `[first, last]` по возрастанию |
| `print()` | Выводит ключи по возрастанию в `std::cout`, разделяя пробелами |

Доступ по ключу выполняется через `at`; для получения копии достаточно присвоить результат отдельной переменной. Изменение значения через `at` не меняет ключ и размер дерева. Результаты `entries`, `keys` и `range` — самостоятельные копии данных.

Форма дерева и значение корня зависят от последовательности операций. При копировании форма исходного дерева сохраняется.

### Ошибки и пустое дерево

| Ситуация | Поведение |
|---|---|
| `replace`, `remove` на пустом дереве | `std::logic_error` |
| Ключ отсутствует в непустом дереве при вызове этих методов | `std::out_of_range` |
| Ключ отсутствует при вызове `at`, в том числе в пустом дереве | `std::out_of_range` |
| `get_root`, `min`, `max` на пустом дереве | `std::logic_error` |
| `range(first, last)`, где `first > last` | `std::invalid_argument` |
| `containsKey` на пустом дереве | `false` |
| `entries`, `keys`, допустимый `range` на пустом дереве | Пустой массив |
| `print` на пустом дереве | Вывод отсутствует |

### Гарантии при исключениях

- Ошибка сравнения, копирования или выделения памяти при вставке оставляет дерево без изменений и утечек.
- Ошибка сравнения при поиске удаляемого элемента оставляет дерево без изменений.
- Удаление не присваивает ключи и значения оставшихся элементов. Наличие двух детей не требует такого присваивания.
- При ошибке копирования ключа или значения либо выделения памяти частично созданная копия освобождается. При копирующем присваивании получатель сохраняет прежнее содержимое.
- Очистка удаляет узлы снизу вверх, используя связи с родителями. Она обходится без рекурсии и выделения памяти.
- Перемещение объявлено `noexcept`. Деструкторы ключей и значений должны завершаться без исключений.
- `replace` и изменение через `at` зависят от гарантий самого `Data`: откат изменения значения не предусмотрен.

## RedBlackTree и Map

`RedBlackTree` поддерживает все операции базового дерева. Вставка и удаление дополнительно восстанавливают баланс.

После каждой завершённой операции выполняются свойства:

1. Каждый узел имеет красный или чёрный цвет.
2. Корень чёрный.
3. Отсутствующий потомок считается чёрным листом.
4. У красного узла оба потомка чёрные.
5. Все пути от узла до отсутствующих потомков содержат одинаковое количество чёрных узлов.

Дополнительные методы `isRed(key)` и `isBlack(key)` проверяют цвет найденного узла. На пустом дереве они бросают `std::logic_error`, при отсутствии ключа в непустом — `std::out_of_range`.

Доступны пустой конструктор и конструктор с одним ключом и значением `Data()`. Поддерживаются копирование и перемещение. Копирование сохраняет структуру дерева и цвета узлов. Если создание копии завершается исключением, частичная копия освобождается, а получатель копирующего присваивания сохраняет прежнее содержимое. Отдельного конструктора с ключом и значением у `RedBlackTree` нет.

`Map` имеет тот же контракт: это другое имя того же типа.

## Сложность

`n` — число элементов, `h` — высота, `k` — число элементов в результате диапазона. Сравнение, копирование и уничтожение одного элемента считаются операциями постоянной стоимости.

| Операция | BinaryTree | RedBlackTree / Map |
|---|---|---|
| Поиск, вставка, удаление, замена значения | `O(h)`, в худшем случае `O(n)` | `O(log(n + 1))` |
| `min`, `max` | `O(h)` | `O(log(n + 1))` |
| `get_root`, `size` | `O(1)` | `O(1)` |
| `entries`, `keys`, `print` | `O(n)` | `O(n)` |
| `range` | `O(h + k)` | `O(log(n + 1) + k)` |
| Уничтожение | `O(n)` времени, `O(1)` дополнительной памяти | То же |

Обходы используют до `O(h)` дополнительной памяти, возвращаемые массивы — `O(n)` или `O(k)`. Копирование строит дерево за `O(n)` времени и использует `O(1)` дополнительной памяти помимо новых узлов. Копирующее присваивание занимает `O(n + m)`. Перемещающий конструктор работает за `O(1)`, перемещающее присваивание — за `O(m)`, где `m` — прежний размер получателя.
