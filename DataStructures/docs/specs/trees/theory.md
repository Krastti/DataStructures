# Деревья: шпаргалка

## Основные понятия

- **Корень** — узел без родителя.
- **Лист** — узел без детей.
- **Поддерево** — узел со всеми его потомками.
- **Глубина узла** — число рёбер от корня до него.
- **Высота дерева** — максимальная глубина. У дерева из одного узла высота 0.
- **Бинарное дерево** — у каждого узла не более двух детей.
- **Бинарное дерево поиска, BST** — ключи всего левого поддерева меньше ключа узла, всего правого — больше.

В реализации проекта ключи уникальны. Порядок определяется ключами, а значения могут быть любыми допустимыми данными.

## Поиск и обход

Поиск: сравнить ключ с текущим узлом. Меньше — идти влево, больше — вправо, равен — элемент найден. Пустая ветвь означает отсутствие ключа.

| Обход | Порядок | Применение |
|---|---|---|
| Симметричный, inorder | Левое поддерево → узел → правое | Ключи BST по возрастанию |
| Прямой, preorder | Узел → левое → правое | Обработка родителя перед детьми |
| Обратный, postorder | Левое → правое → узел | Освобождение детей перед родителем |
| По уровням, BFS | От корня, уровень за уровнем | Просмотр структуры; нужна очередь |

Полный обход занимает `O(n)`. В проекте упорядоченная выгрузка выполняется симметричным обходом.

**Минимум:** идти влево до конца. **Максимум:** вправо до конца.

**Преемник** — узел со следующим по величине ключом:

1. Если есть правое поддерево — взять его минимум.
2. Иначе подниматься, пока не перейдём от левого ребёнка к родителю.
3. Если такого родителя нет, текущий ключ максимальный.

## Вставка и удаление в BST

**Вставка:** найти пустую ветвь обычным поиском и добавить лист. Повторный ключ в проекте игнорируется.

**Удаление:**

| Дети удаляемого узла | Действие |
|---|---|
| Нет детей | Убрать лист |
| Один ребёнок | Поставить ребёнка на место узла |
| Два ребёнка | Поставить преемника на место узла; его прежнюю позицию занимает его правый ребёнок |

У преемника в правом поддереве нет левого ребёнка. Поэтому его перенос сводится к случаю с одним ребёнком или без детей.

В `BinaryTree`, `RedBlackTree` и использующем `Map` множестве `Set` переносится сам узел-преемник. Ключи и значения при удалении не присваиваются. Это позволяет удалять элементы с бросающим присваиванием и сохраняет ссылки на оставшиеся значения.

## Зачем нужна балансировка

Поиск, вставка и удаление занимают `O(h)`. Если добавлять отсортированные ключи в обычное BST, получится цепочка с высотой `n - 1`. Операции станут линейными.

Красно-чёрное дерево ограничивает высоту: `h ≤ 2 log₂(n + 1)`. Поэтому операции по ключу имеют сложность `O(log(n + 1))` независимо от порядка вставки.

## Свойства красно-чёрного дерева

1. Узел либо красный, либо чёрный.
2. Корень чёрный.
3. Пустые потомки, `NIL`, считаются чёрными.
4. У красного узла нет красных детей.
5. От любого узла до всех его `NIL`-потомков проходит одинаковое число чёрных узлов.

**Чёрная высота** — число чёрных узлов на пути до `NIL`. Здесь сам исходный узел не считаем, конечный `NIL` считаем. Для сравнения путей важно использовать одно соглашение.

На самом длинном пути красные узлы могут чередоваться с чёрными. На самом коротком красных может не быть. Из-за равенства чёрной высоты пути отличаются по длине не более чем вдвое.

## Повороты

Левый поворот вокруг `x`:

```text
      x                 y
     / \               / \
    A   y      →      x   C
       / \           / \
      B   C         A   B
```

До и после поворота порядок один: `A < x < B < y < C`. Правый поворот — обратное преобразование.

Поворот меняет форму дерева, сохраняет порядок ключей и занимает `O(1)`. Цвета при необходимости меняются отдельно.

## Балансировка после вставки

Новый некорневой узел вставляется красным: чёрная высота путей остаётся прежней. Возможное нарушение — красный родитель у красного узла.

Обозначения: `x` — текущий узел, `p` — родитель, `g` — дед, `u` — дядя, то есть второй ребёнок деда.

| Ситуация | Действие |
|---|---|
| Родитель чёрный | Балансировка не нужна |
| Родитель и дядя красные | Сделать их чёрными, деда красным; продолжить проверку от деда |
| Родитель красный, дядя чёрный; узлы образуют «угол» | Повернуть вокруг родителя, чтобы получить «линию» |
| Родитель красный, дядя чёрный; узлы образуют «линию» | Сделать родителя чёрным, деда красным; повернуть вокруг деда |

«Угол» — левый–правый или правый–левый переход. «Линия» — левый–левый или правый–правый. Пустой дядя считается чёрным. В конце корень окрашивается в чёрный.

## Балансировка после удаления

Если из прежней позиции убран красный узел, чёрная высота не меняется. Если чёрный узел заменён красным ребёнком, ребёнка достаточно сделать чёрным.

В остальных случаях на одной ветви не хватает чёрного узла. Это называют **дефицитом чёрного** или **двойной чернотой**. Отдельного такого цвета в узле нет.

При двух детях для решения о балансировке важен прежний цвет преемника. На новой позиции преемник получает цвет удаляемого узла.

Пусть `x` — ветвь с дефицитом, `p` — её родитель, `s` — брат. Ближний ребёнок брата расположен со стороны `x`, дальний — с противоположной.

| Случай | Действие |
|---|---|
| Брат красный | Сделать брата чёрным, родителя красным и повернуть родителя в сторону `x`. После этого рассматривать нового брата |
| Брат чёрный, оба его ребёнка чёрные | Сделать брата красным и перенести дефицит на родителя. Красный родитель поглощает дефицит, становясь чёрным |
| Брат чёрный, ближний ребёнок красный, дальний чёрный | Перекрасить брата и ближнего ребёнка, повернуть брата от `x`; перейти к следующему случаю |
| Брат чёрный, дальний ребёнок красный | Передать брату цвет родителя, сделать родителя и дальнего ребёнка чёрными, повернуть родителя в сторону `x`. Дефицит устранён |

Если `x` слева, поворот родителя в его сторону — левый, а поворот брата от него — правый. Для `x` справа всё зеркально. Если дефицит дошёл до корня, его можно отбросить: чёрная высота всех путей уменьшается одинаково.

## Что проверять после операции

- Ключи всего левого поддерева меньше текущего, всего правого — больше.
- Родительские связи согласованы, у корня родителя нет.
- Количество узлов совпадает с размером, симметричный обход даёт возрастающие ключи.
- Корень красно-чёрного дерева чёрный.
- Красные узлы не соседствуют по связи родитель–ребёнок.
- Чёрная высота левого и правого поддеревьев одинакова у каждого узла.
