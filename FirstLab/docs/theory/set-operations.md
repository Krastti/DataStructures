# Операции над множествами в Set

`Set<Key>` хранит каждый элемент как ключ красно-чёрного дерева. При повторной вставке того же ключа дерево сохраняет один узел. `contains` проверяет принадлежность элемента множеству поиском по дереву.

Возьмём `a = {1, 2, 4}` и `b = {2, 3, 4}`.

| Вызов | Какие элементы берём | Результат |
|---|---|---|
| `a.unionWith(b)` | Элемент есть хотя бы в одном множестве | `{1, 2, 3, 4}` |
| `a.intersection(b)` | Элемент есть в обоих множествах | `{2, 4}` |
| `a.difference(b)` | Элемент есть в `a` и отсутствует в `b` | `{1}` |
| `b.difference(a)` | Элемент есть в `b` и отсутствует в `a` | `{3}` |

## Объединение

`a.unionWith(b)` сначала копирует дерево `a` в результат. В нём уже есть `1`, `2` и `4`. Затем метод обходит дерево `b` и вызывает `insert` для каждого ключа. При вставке `2` и `4` дерево находит существующие ключи. Только `3` создаёт новый узел.

## Пересечение и вычитание

Обе операции начинают с пустого результата и обходят ключи `a`. Для каждого ключа вызывается `b.contains(key)`. Пересечение добавляет ключ при успешном поиске, а вычитание — при неуспешном.

| Ключ из `a` | Есть в `b` | Куда попадёт |
|---|---|---|
| `1` | Нет | В разность |
| `2` | Да | В пересечение |
| `4` | Да | В пересечение |

У вычитания важен порядок операндов. При вызове `b.difference(a)` обход идёт по `b`, поэтому результат содержит `3`. Вычитание множества из самого себя даёт пустой результат.

## Как устроен обход и сколько он стоит

Ключи обходятся в порядке возрастания. `firstNode()` начинает с корня и идёт по левым указателям до самого маленького ключа. Если корень пуст, он сразу возвращает `nullptr`.

Дальше цикл обрабатывает ключ текущего узла и вызывает `getSuccessor()` для перехода к следующему.

- Если есть правый ребёнок, спускаемся к нему и затем идём влево до упора. Так находим наименьший ключ правого поддерева.
- Если правого ребёнка нет, поднимаемся по `parent`, пока приходим к родителю из его правой ветви. Первый родитель, к которому пришли слева, и есть следующий узел. Если дошли выше корня, возвращаем `nullptr` и завершаем обход.

Пусть у корня `4` дети `2` и `6`, а у `6` есть левый ребёнок `5`. После `2` поднимаемся к `4`. После `4` спускаемся к `6` и идём влево к `5`. После `5` поднимаемся к `6`. Из `6` приходим к `4` справа и продолжаем подъём, пока не получим `nullptr`.

Один переход может пройти по всей высоте дерева. За полный обход каждое ребро проходится не более двух раз, поэтому суммарное время составляет `O(n)`, а дополнительная память для обхода — `O(1)`. Цикл использует ключ непосредственно из узла. Вставка в результирующее множество создаёт собственный узел.

Пусть в `a` находится `n` элементов, в `b` — `m`, а пересечение или разность содержит `k` элементов.

- **Объединение** копирует `n` узлов и выполняет `m` вставок в дерево размером не больше `n + m`. Время — `O(n + m log(n + m + 2))`.
- **Пересечение и вычитание** делают `n` поисков в `b` и `k` вставок в результат. Время — `O(n log(m + 2) + k log(k + 2))`.

У каждой операции свой результат со своими узлами. Можно удалить ключ из результата и по-прежнему найти его в исходном множестве.

## Проверка включения

`a.isSubsetOf(b)` проверяет, входит ли каждый элемент `a` в `b`. Если в `a` больше элементов, метод сразу возвращает `false`. Иначе он обходит ключи `a` и для каждого вызывает `b.contains(key)`. Обход заканчивается на первом ключе, которого нет в `b`.

Если `a = {1, 2}`, а `b = {1, 2, 3}`, то `a.isSubsetOf(b)` возвращает `true`. В обратную сторону проверка сразу отклоняется по размеру. Пустое множество входит в любое, поскольку в нём нет ключа, на котором проверка могла бы завершиться с `false`.

Сравнение размеров занимает `O(1)`. Если нужен обход, для каждого из `n` ключей выполняется до одного поиска в дереве из `m` узлов. В худшем случае это `O(n log(m + 2))`.

## Равенство

`a == b` сначала сравнивает размеры, затем вызывает `a.isSubsetOf(b)`. Одного направления хватает благодаря уникальности элементов. Если все элементы `a` присутствуют в `b` и размеры совпадают, в `b` не может быть дополнительных элементов.

Например, множества, полученные вставкой `1, 2, 3, 4` и `4, 3, 2, 1`, равны. Для `{1, 2}` и `{1, 3}` размеры совпадают, но поиск `2` во втором множестве возвращает `false`. Два пустых множества равны. При разных размерах проверка занимает `O(1)`, при одинаковом размере `n` — до `O(n log(n + 2))`.

## Преобразование map

`a.map(transform)` вызывает `transform(key)` для каждого ключа и вставляет результат в новое множество того же типа. Если несколько ключей дают одно значение, вставка сохраняет только один экземпляр. Например, преобразование в остаток от деления на два переводит `{1, 2, 3}` в `{0, 1}`.

## Фильтрация where

`a.where(predicate)` вызывает `predicate(key)` для каждого ключа. Если условие выполняется, метод вставляет исходный ключ в новое множество. Фильтр на чётность переводит `{1, 2, 3}` в `{2}`.

## Свёртка reduce

`a.reduce(combine, initial)` начинает с переданного значения `initial`. На каждом шаге метод вызывает `combine(key, accumulator)` и сохраняет возвращённое значение как новый аккумулятор. Ключ передаётся первым. Обход идёт по возрастанию ключей, поэтому порядок вставки элементов в дерево не влияет на последовательность вызовов.

Для `{1, 2, 3}`, начального значения `4` и функции `combine(key, accumulator) = 2 * key + 3 * accumulator` получаются следующие шаги.

| Ключ | Аккумулятор до вызова | Аккумулятор после вызова |
|---|---|---|
| 1 | 4 | 14 |
| 2 | 14 | 46 |
| 3 | 46 | 144 |

В примере задания указан результат `132`. При подстановке в формулу второй шаг даёт `2 * 2 + 3 * 14 = 46`, а третий — `2 * 3 + 3 * 46 = 144`.

Тип результата задаёт начальное значение. Например, множество целых ключей можно свернуть в строку, если передать начальную строку и функцию, которая возвращает строку.

Все три метода используют `firstNode()` и `getSuccessor()`. На пустом множестве `map` и `where` возвращают пустое множество, а `reduce` — начальное значение. Нулевой указатель на функцию приводит к `std::invalid_argument`.

Без учёта работы переданной функции `map` занимает до `O(n log(n + 2))`, `where` — `O(n + k log(k + 2))` при `k` прошедших фильтр ключах, а `reduce` — `O(n)` шагов свёртки.
