# Сохранение множества в строку

`toString()` записывает ключи по возрастанию. `fromString(text)` читает записи и возвращает новое множество. Форма дерева и цвета узлов в строку не записываются.

## Формат

Каждая запись состоит из десятичной длины, двоеточия и текста ключа. Длина измеряется в байтах. Записи идут подряд, поэтому внутри ключа могут быть пробелы, двоеточия и переводы строк.

| Множество | Результат `toString()` |
|---|---|
| Пустое | Пустая строка |
| Один пустой строковый ключ | `0:` |
| Числа `{-12, 5}` | `3:-121:5` |
| Строки `{"", "a b", "a:b"}` | `0:3:a b3:a:b` |

В последнем примере `0:` задаёт пустой ключ. Следующий префикс `3:` задаёт длину строки `a b`, после которой сразу идёт третья запись. В `a:b` двоеточие входит в три байта ключа.

## Запись и чтение

При записи `firstNode()` находит наименьший ключ, а `getSuccessor()` переводит цикл к следующему узлу по указателям на детей и родителя. Для каждого ключа метод получает его текст, записывает длину и дописывает сам текст.

При чтении метод ищет двоеточие после длины, проверяет длину и берёт ровно столько байтов. Полученный ключ вставляется в дерево, после чего метод переходит к следующей записи. Порядок записей на входе может быть любым. Повторяющиеся ключи хранятся один раз. Если длина неверна, данных не хватает или текст ключа не удаётся прочитать целиком, метод выбрасывает `std::invalid_argument`.

## Преобразование ключей

Сохранение и чтение доступны для `std::string`, целых и вещественных типов.

| Тип ключа | Запись | Чтение |
|---|---|---|
| `std::string` | Копируем байты ключа | Создаём строку из этих байтов |
| Целое число | `std::to_string` пишет десятичное число | `std::from_chars` читает число с проверкой диапазона типа |
| Вещественное число | `std::to_chars` пишет число с точкой и точностью, достаточной для обратного чтения | `std::from_chars` восстанавливает число |

Типы вроде `char` записываются как целые числа. `bool` записывается как `0` или `1`. Для чисел проверяем, что `from_chars` дошёл до конца записи. Например, `3:12x` недопустима для `Set<int>`. `NaN` отклоняется при записи и чтении, поскольку он не задаёт упорядоченный ключ.

При длине строки `L` и числе записей `n` обход и формирование строки занимают `O(n + L)`, если преобразование ключей линейно по длине их записи. Чтение добавляет до `O(n log(n + 1))` на вставки, если сравнение ключей занимает постоянное время.
