# MiniLang на C++

MiniLang — учебный интерпретатор на C++20, разработанный по образцу [Java-проекта MiniLang](https://github.com/Krastti/MiniLang). Он читает программы из файлов, вычисляет выражения и хранит переменные в структурах данных DataStructures.

```minilang
remember total = (2 + 3) * 4
print total
print total >= 18
print "готово"
```

Программа выведет следующие строки.

```text
20.0
true
готово
```
