# MiniLang на C++

MiniLang — учебный интерпретатор на C++20, разработанный по образцу [Java-проекта MiniLang](https://github.com/Krastti/MiniLang). Он читает программы из файлов, вычисляет выражения и выполняет ветвления `when`, циклы `repeat while` и `for … in range(…)`. Переменные хранятся в структурах данных DataStructures.

```minilang
remember total = (2 + 3) * 4
print total
print total >= 18
print "готово"
```

Программа выведет следующие строки.

```text
20.0
true
готово
```

## Пример с библиотекой

Основная программа `Interpreter/examples/main.mini` подключает соседний файл `math.mini` и выводит квадрат числа 10.

```bash
/tmp/ds-build/MiniLangCpp Interpreter/examples/main.mini
```

Ожидаемый вывод — `100.0`. Путь в `using "math.mini"` отсчитывается от каталога основного файла. Вложенные подключения используют каталог своей библиотеки. Программу можно запускать из другого рабочего каталога, передав корректный путь к основному файлу.

Для GUI запустите `/tmp/ds-build/MiniLangGui`, нажмите «Открыть .mini» и выберите `Interpreter/examples/main.mini`. Открытие сразу запускает программу. После изменения текста нажмите «Запустить» или «Пошагово». Кнопка «Следующий шаг» и F8 продолжают пошаговое выполнение, «Остановить» завершает его.

Для введённого в редакторе текста без пути GUI запрашивает каталог при относительном `using`. Выбранный каталог сохраняется для повторных запусков. Отмена выбора отменяет запуск. Открытие другого файла устанавливает его каталог как основу подключений.
