# План реализации MiniLang на C++

Текущее поведение языка описано в [спецификации](specification.md).

## Реализовано

- [x] **Отрицательные числовые литералы.** Поддерживаются `-5` и `-0.5`, включая аргументы функций и границы циклов. Парсер сохраняет минус в `NumberLiteral::lexeme`, дерево выражения строится через `makeLeaf` и `makeBinary`. Проверены форма AST, вычитание, знак нуля, ошибочный ввод, CLI и пошаговый показ числового листа в GUI. Release-сборка с Qt прошла, CTest — 309 из 309. Под ASan и UBSan с контролем утечек прошли 154 из 154 проверок MiniLang.

- [x] **Подключение библиотек.** `using` загружает файлы относительно подключающего исходника, обрабатывает вложенные зависимости, повторы и циклы. CLI и GUI используют общий загрузчик. Для текста GUI без пути доступен выбор базового каталога, пошаговый режим включает библиотечные функции. [План добавления `using`](using-roadmap.md)

- [x] **Дробные литералы.** Поддерживается запись с цифрами с обеих сторон точки, например `0.5` и `12.25`. Тесты проверяют вычисления с дробями и отклонение записей вида `.5`, `1.` и `1.2.3`. [Тесты лексера](../tests/LexerTests.cpp) · [Тесты исполнителя](../tests/InterpreterTests.cpp)
- [x] **Числовые операции.** Префиксные и постфиксные `++` и `--` работают с числовыми переменными и имеют приоритет выше `*` и `/`. `+=` и `-=` доступны как отдельные инструкции. Тесты проверяют приоритет, возвращаемое значение, изменение переменной и ошибки типов. Отрицательные литералы описаны отдельным пунктом выше. [Тесты парсера](../tests/ParserTests.cpp) · [Тесты исполнителя](../tests/InterpreterTests.cpp)
- [x] **Функции.** Поддерживаются короткая форма с выражением и многострочная форма с завершающим `return`. Аргументы хранятся в `Array` и вычисляются слева направо. Каждый вызов получает отдельный перемещаемый некопируемый кадр в `Stack<CallFrame>`, который снимается при возврате или исключении. Тесты проверяют вложенные вызовы, рекурсию, изоляцию локальных переменных и восстановление окружения после ошибки. [Спецификация функций](specification.md#функции) · [Тесты исполнителя](../tests/InterpreterTests.cpp)

## Проверки

- [x] Собрать проект с `BUILD_GUI=ON` и запустить CTest. Сборка Release включала `MiniLangGui`. Итоговая проверка `using` — 299 из 299 тестов проекта, включая 144 проверки с меткой `Interpreter` и группу из восьми сценариев MiniLang GUI в Qt offscreen.
- [x] Повторить проверки MiniLang с AddressSanitizer и UndefinedBehaviorSanitizer с включённой проверкой утечек. Прошли 144 из 144 проверок с меткой `Interpreter`, включая загрузчик, CLI и GUI. Проверены освобождение частичного AST и загруженных файлов, очистка областей видимости и кадров вызовов, остановка рабочего потока. LeakSanitizer запускался вне песочницы из-за ограничения ptrace. [Тесты разбора](../tests/ExpressionTreeAllocationTests.cpp) · [Тесты выполнения](../tests/InterpreterTests.cpp)

## Оставшиеся задачи

### Диагностика

- [ ] Добавить в `Token` поля `line` и `column` с нумерацией от единицы. Отслеживать положение в лексере с учётом LF, CRLF и EOF.
- [ ] Передавать координаты в необходимые узлы AST и показывать их в сообщениях об ошибках лексического анализа, разбора и выполнения. Добавить тесты координат для всех трёх этапов.

### Расширение языка

- [ ] Добавить `return` внутри ветвей `when` и `otherwise` в функциях. [План возврата из ветвей](conditional-return-roadmap.md)

- [ ] Добавить перегрузку функций по количеству параметров. [План перегрузки функций](function-overloading-roadmap.md)

- [ ] Уточнить, нужен ли унарный `+`. При добавлении определить его приоритет и взаимодействие с числовыми литералами со знаком, обновлениями и бинарными операторами.
- [ ] Определить и реализовать экранирование и допустимые операции над строками. Сейчас строки можно хранить, передавать в функции, возвращать и выводить. Обратная косая черта сохраняется как обычный символ. Проверить допустимые и ошибочные последовательности, результаты операций и ошибки типов.
