# Спецификация MiniLang на C++

Документ описывает поведение текущей версии. MiniLang выполняет текстовые программы с инструкциями сохранения переменных и вывода. Сборка и запуск описаны в [документации CLI](cli.md), будущие возможности — в [плане реализации](implementation-plan.md).

## Исходный текст и токены

Лексер читает текст слева направо. Вне строк он пропускает пробелы (ASCII 0x20) и горизонтальные табуляции (0x09). LF и пара CRLF образуют по одному токену NEWLINE. Одиночный CR вызывает лексическую ошибку. После последнего байта лексер добавляет EOF, в том числе для пустого файла.

В EBNF квадратные скобки обозначают необязательную часть, фигурные — ноль или более повторений, вертикальная черта — выбор, круглые скобки — группировку. Терминалы заключены в кавычки. Обозначения в вопросительных знаках задают классы байтов.

```ebnf
NUMBER     = digit, { digit } ;
IDENTIFIER = name-start, { name-start | digit } ;
STRING     = '"', { string-byte }, '"' ;
NEWLINE    = [ CR ], LF ;

digit       = ? ASCII-цифра от 0 до 9 ? ;
name-start  = ? ASCII-буква от A до Z или от a до z либо "_" ? ;
string-byte = ? любой байт, кроме двойной кавычки, CR и LF ? ;
CR          = ? байт 0x0D ? ;
LF          = ? байт 0x0A ? ;
```

- Лексер забирает полную последовательность цифр или символов имени. Имя, совпавшее с `remember` или `print`, становится ключевым словом вместо IDENTIFIER. Регистр значим. Например, `print2`, `Print`, `true`, `false`, `when`, `otherwise` и `repeat` распознаются как имена.
- Операторы `==`, `!=`, `<=`, `>=` распознаются раньше одиночных `=`, `<` и `>`. Остальные одиночные токены — `+`, `-`, `*`, `/`, `(` и `)`. Одиночный `!` вызывает ошибку.
- Строка заканчивается первой двойной кавычкой после открывающей. Пустая строка допустима. Обратная косая черта является обычным байтом и сохраняется при выводе. CR, LF или EOF до закрывающей кавычки вызывают лексическую ошибку.
- Между токенами пробелы необязательны, если граница определяется правилами лексера. Например, `print(2)` допустимо, а `print2` образует один идентификатор. Точка, запятая, `;` и `#` вне строки вызывают лексическую ошибку. Синтаксиса комментариев нет.

## Грамматика программы

Грамматика применяется к токенам. Строчные имена обозначают правила, прописные — токены из предыдущего раздела, а EOF — маркер конца ввода.

```ebnf
program        = { [ statement ], NEWLINE }, [ statement ], EOF ;
statement      = "remember", IDENTIFIER, "=", expression
               | "print", expression ;

expression     = equality ;
equality       = comparison, { ( "==" | "!=" ), comparison } ;
comparison     = addition, { ( "<" | "<=" | ">" | ">=" ), addition } ;
addition       = multiplication, { ( "+" | "-" ), multiplication } ;
multiplication = primary, { ( "*" | "/" ), primary } ;
primary        = NUMBER | STRING | IDENTIFIER | "(", expression, ")" ;
```

Файл может быть пустым или содержать пустые строки. Последняя инструкция может завершаться сразу на EOF. На одной строке допускается одна инструкция. Перенос внутри инструкции или выражения, включая выражение в скобках, вызывает синтаксическую ошибку. Знак `=` входит только в конструкцию `remember`. Операторы `+` и `-` здесь всегда бинарные.

## Значения и выражения

| Тип | Как получается | Как печатается |
|---|---|---|
| Число | Десятичный целочисленный литерал либо результат арифметики. Хранится как C++ `double`. | Короткая запись `std::to_chars`, независимо от локали. Если в записи конечного числа нет точки, в конец мантиссы добавляется `.0`, в том числе перед показателем степени. |
| Логическое значение | Результат числового сравнения или проверки равенства. | `true` или `false`. |
| Строка | Содержимое литерала между кавычками. | Исходные байты содержимого без внешних кавычек. |

Числовой литерал преобразуется во время вычисления. Ведущие нули допустимы. Если преобразование выходит за диапазон `double`, выполнение останавливается с ошибкой. Отрицательные и дробные числа могут получаться из операций. Арифметика и сравнения следуют правилам `double`, с отдельной проверкой делителя на ноль. Например, арифметическое переполнение может дать бесконечность. Бесконечность и NaN выводятся в форме, которую возвращает `std::to_chars`, например `inf`, `-inf` и `nan`. Операторы `==` и `!=` сравнивают значения `double` без допуска.

Идентификатор в выражении возвращает значение переменной, включая строку или логическое значение. Обращение к отсутствующему имени вызывает ошибку выполнения. Скобки меняют группировку и возвращают значение вложенного выражения.

| Приоритет, от высокого к низкому | Операторы | Тип операндов | Результат |
|---|---|---|---|
| 1 | `*`, `/` | Два числа | Число |
| 2 | `+`, `-` | Два числа | Число |
| 3 | `<`, `<=`, `>`, `>=` | Два числа | Логическое значение |
| 4 | `==`, `!=` | Два числа | Логическое значение |

Операции одного уровня группируются слева направо. Например, `20 / 5 / 2` означает `(20 / 5) / 2` и даёт `2.0`. Для каждой бинарной операции сначала вычисляется левый операнд, затем правый. Типы проверяются после успешного вычисления обоих операндов. Преобразований между типами нет. Деление на `0.0` и `-0.0` вызывает ошибку.

Запись `1 < 2 < 3` синтаксически допустима и означает `(1 < 2) < 3`. Внешний оператор получает логическое значение слева и завершает выполнение с ошибкой типа. Равенство строк и логических значений тоже вызывает ошибку типа.

## Инструкции и выполнение

Выполнение начинается после успешного лексического и синтаксического анализа всего файла. Инструкции выполняются по порядку. Каждый запуск начинает с пустой таблицей переменных.

| Инструкция | Порядок действий |
|---|---|
| `remember имя = выражение` | Вычисляет выражение в текущей таблице. При успехе создаёт переменную или заменяет её значение, в том числе значением другого типа. При ошибке вычисления таблица сохраняет прежнее состояние. |
| `print выражение` | Вычисляет выражение, форматирует значение и записывает его с завершающим LF. Для пустой строки записывает один LF. Если вычисление завершилось ошибкой, вывод для этой инструкции не начинается. |

После `remember x = 2` инструкция `remember x = x + 3` читает прежнее значение `x` и сохраняет `5.0`. Если вместо неё выполнить `remember x = 1 / 0`, ошибка возникнет до изменения `x`, и программа остановится.

## Ошибки

| Этап | Условия и примеры | Последствие |
|---|---|---|
| Лексический анализ | Недопустимый байт или незакрытая строка. Например, `print 1.5` или `print "a` до конца строки. | Файл не выполняется. |
| Синтаксический анализ | Неизвестная инструкция, пропущенное имя или `=`, пустые или незакрытые скобки, недостающий операнд либо лишний токен после инструкции. Например, `remember x 2`, `print ()`, `print 1 +` или `print 1 print 2`. | Файл не выполняется, даже если ошибке предшествуют корректные инструкции. |
| Выполнение | Неизвестная переменная, число вне диапазона, неподходящий тип операнда, деление на ноль или сбой записи. Например, `print missing`, `print "a" == "a"` или `print 1 / 0`. | Выполнение останавливается. Уже записанный вывод сохраняется. |

CLI сообщает этап и причину ошибки через стандартный поток ошибок. Координаты строки и столбца пока отсутствуют. Коды завершения и ошибки работы с файлами описаны в [документации CLI](cli.md).

## Контрольная программа

```minilang
remember x = 10
remember y = (x + 2) * 3
print y
print y >= 30
remember x = y / 2
print x
```

Ожидаемый вывод:

```text
36.0
true
18.0
```

Этот пример и граничные случаи проверяются в [тестах интерпретатора](../tests/) и [сквозных проверках CLI](../tests/CliTests.cmake).
