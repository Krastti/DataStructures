# Спецификация MiniLang на C++

Документ описывает поведение текущей версии. MiniLang выполняет текстовые программы с переменными, выводом, ветвлениями, циклами и функциями. [Сборка и запуск](../../README.md#обновление-команды-mini) · [План реализации](implementation-plan.md)

## Исходный текст и токены

Лексер читает текст слева направо. Вне строк он пропускает пробелы (ASCII 0x20) и горизонтальные табуляции (0x09). LF и пара CRLF образуют по одному токену NEWLINE. Одиночный CR вызывает лексическую ошибку. После последнего байта лексер добавляет EOF, в том числе для пустого файла.

В EBNF квадратные скобки обозначают необязательную часть, фигурные — ноль или более повторений, вертикальная черта — выбор, круглые скобки — группировку. Терминалы заключены в кавычки. Обозначения в вопросительных знаках задают классы байтов.

```ebnf
NUMBER     = digit, { digit }, [ ".", digit, { digit } ] ;
IDENTIFIER = name-start, { name-start | digit } ;
STRING     = '"', { string-byte }, '"' ;
NEWLINE    = [ CR ], LF ;

digit       = ? ASCII-цифра от 0 до 9 ? ;
name-start  = ? ASCII-буква от A до Z или от a до z либо "_" ? ;
string-byte = ? любой байт, кроме двойной кавычки, CR и LF ? ;
CR          = ? байт 0x0D ? ;
LF          = ? байт 0x0A ? ;
```

- Лексер забирает полную последовательность цифр или символов имени. При точном совпадении с `remember`, `print`, `when`, `otherwise`, `repeat`, `while`, `for`, `in`, `range`, `function`, `return` или `end` он выдаёт токен ключевого слова. Эти слова зарезервированы. Регистр значим, поэтому `when2`, `When`, `true` и `false` распознаются как имена.
- Двухсимвольные токены `==`, `!=`, `<=`, `>=`, `->`, `++`, `--`, `+=` и `-=` распознаются целиком при смежных символах. Допустимые одиночные токены — `=`, `<`, `>`, `+`, `-`, `*`, `/`, `(`, `)` и `,`. Одиночный `!` вызывает ошибку.
- Строка заканчивается первой двойной кавычкой после открывающей. Пустая строка допустима. Обратная косая черта является обычным байтом и сохраняется при выводе. CR, LF или EOF до закрывающей кавычки вызывают лексическую ошибку.
- В дробном литерале точка стоит между цифрами. Например, `0.5` и `12.25` допустимы, а `.5`, `1.` и `1.2.3` вызывают лексическую ошибку.
- Между токенами пробелы необязательны, если граница определяется правилами лексера. Например, `print(2)` допустимо, а `print2` образует один идентификатор. Символы `;` и `#` вне строки вызывают лексическую ошибку. Синтаксиса комментариев нет.

## Грамматика программы

Грамматика применяется к токенам. Строчные имена обозначают правила, прописные — токены из предыдущего раздела, а EOF — маркер конца ввода.

```ebnf
program        = { [ top-level ], NEWLINE }, [ top-level ], EOF ;
top-level      = statement | function-declaration ;
statement      = "remember", IDENTIFIER, "=", expression
               | IDENTIFIER, ( "+=" | "-=" ), expression
               | update
               | "print", expression
               | when-statement
               | repeat-statement
               | for-statement ;

when-statement   = "when", expression, NEWLINE, body,
                   [ "otherwise", NEWLINE, body ], "end" ;
repeat-statement = "repeat", "while", expression, NEWLINE, body, "end" ;
for-statement    = "for", IDENTIFIER, "in", "range", "(", expression, ")", NEWLINE, body, "end" ;
body             = { [ statement ], NEWLINE } ;

function-declaration = "function", IDENTIFIER, "(", [ parameters ], ")", "->",
                       ( expression | NEWLINE, body, "return", expression, NEWLINE, { NEWLINE } ), "end" ;
parameters           = IDENTIFIER, { ",", IDENTIFIER } ;
call                 = IDENTIFIER, "(", [ arguments ], ")" ;
arguments            = expression, { ",", expression } ;

expression     = equality ;
equality       = comparison, { ( "==" | "!=" ), comparison } ;
comparison     = addition, { ( "<" | "<=" | ">" | ">=" ), addition } ;
addition       = multiplication, { ( "+" | "-" ), multiplication } ;
multiplication = unary, { ( "*" | "/" ), unary } ;
unary          = update | primary ;
update         = ( "++" | "--" ), IDENTIFIER | IDENTIFIER, ( "++" | "--" ) ;
primary        = NUMBER | STRING | IDENTIFIER | call | "(", expression, ")" ;
```

Файл может быть пустым или содержать пустые строки. `remember` и `print` занимают по одной строке. Заголовки `when`, `repeat while` и `for` заканчиваются переводом строки. В этих конструкциях `otherwise` и `end` занимают отдельные строки. Последняя инструкция на верхнем уровне, включая завершающий её `end`, может заканчиваться сразу на EOF.

Все объявления функций находятся на верхнем уровне программы. Короткая форма занимает одну строку, например `function square(x) -> x * x end`. В многострочной форме после `->` следует перевод строки. Тело может начинаться сразу с `return` или содержать инструкции, включая вложенные ветвления и циклы. После обязательной строки `return выражение` допустимы пустые строки и завершающий `end`. Вложенные ветви и циклы используют обычные инструкции. Имена параметров в одном объявлении уникальны, а запятые в параметрах и аргументах стоят только между элементами.

Тела и ветви могут быть пустыми и содержать пустые строки. Блок допускает любые инструкции, в том числе вложенные ветвления и циклы. `otherwise` допустим один раз в каждом `when`. Каждый `end` закрывает ближайшую открытую конструкцию. Отступы служат для читаемости, границы задаются токенами.

Перенос внутри выражения, в том числе в скобках и в условиях, вызывает синтаксическую ошибку. Знак `=` входит только в конструкцию `remember`. Одиночные операторы `+` и `-` всегда бинарные. `++` и `--` применяются к имени переменной и могут стоять в выражении или занимать отдельную строку. Составные присваивания `+=` и `-=` занимают отдельную строку.

## Значения и выражения

| Тип | Как получается | Как печатается |
|---|---|---|
| Число | Целый или дробный десятичный литерал либо результат арифметики. Хранится как C++ `double`. | Короткая запись `std::to_chars`, независимо от локали. Если в записи конечного числа нет точки, в конец мантиссы добавляется `.0`, в том числе перед показателем степени. |
| Логическое значение | Результат числового сравнения или проверки равенства. | `true` или `false`. |
| Строка | Содержимое литерала между кавычками. | Исходные байты содержимого без внешних кавычек. |

Числовой литерал преобразуется во время вычисления. Ведущие нули допустимы. Если преобразование выходит за диапазон `double`, выполнение останавливается с ошибкой. Отрицательные и дробные числа могут получаться из операций. Арифметика и сравнения следуют правилам `double`, с отдельной проверкой делителя на ноль. Например, арифметическое переполнение может дать бесконечность. Бесконечность и NaN выводятся в форме, которую возвращает `std::to_chars`, например `inf`, `-inf` и `nan`. Операторы `==` и `!=` сравнивают значения `double` без допуска.

Идентификатор в выражении возвращает значение переменной, включая строку или логическое значение. Обращение к отсутствующему имени вызывает ошибку выполнения. Скобки меняют группировку и возвращают значение вложенного выражения.

| Приоритет, от высокого к низкому | Операторы | Тип операндов | Результат |
|---|---|---|---|
| 1 | `++`, `--` | Имя числовой переменной | Число |
| 2 | `*`, `/` | Два числа | Число |
| 3 | `+`, `-` | Два числа | Число |
| 4 | `<`, `<=`, `>`, `>=` | Два числа | Логическое значение |
| 5 | `==`, `!=` | Два числа | Логическое значение |

Бинарные операции одного уровня группируются слева направо. Например, `20 / 5 / 2` означает `(20 / 5) / 2` и даёт `2.0`. Для каждой бинарной операции сначала вычисляется левый операнд, затем правый. Типы проверяются после успешного вычисления обоих операндов. Преобразований между типами нет. Деление на `0.0` и `-0.0` вызывает ошибку.

`++` прибавляет единицу, `--` вычитает её. Префиксная форма возвращает новое значение, постфиксная — прежнее. Например, при `x = 2.5` выражение `x++ * 2` даёт `5.0` и оставляет в `x` значение `3.5`.

Запись `1 < 2 < 3` синтаксически допустима и означает `(1 < 2) < 3`. Внешний оператор получает логическое значение слева и завершает выполнение с ошибкой типа. Равенство строк и логических значений тоже вызывает ошибку типа.

## Инструкции и выполнение

Выполнение начинается после успешного лексического и синтаксического анализа всего файла. Инструкции выполняются по порядку. Каждый запуск начинает с пустыми таблицами глобальных переменных и функций.

| Инструкция | Порядок действий |
|---|---|
| `remember имя = выражение` | Вычисляет выражение в текущем окружении. При успехе создаёт переменную или заменяет её значение, в том числе значением другого типа. |
| `имя += выражение`, `имя -= выражение` | Читает существующее число по имени, один раз вычисляет правое выражение и записывает сумму или разность. Правый операнд тоже должен быть числом. |
| `++имя`, `--имя`, `имя++`, `имя--` | Меняет существующую числовую переменную на единицу. Значение выражения отбрасывается. |
| `print выражение` | Вычисляет выражение, форматирует значение и записывает его с завершающим LF. Для пустой строки записывает один LF. Если вычисление завершилось ошибкой, вывод для этой инструкции не начинается. |
| `when условие … otherwise … end` | Вычисляет условие один раз. При истинном результате выполняет первую ветвь. При ложном выполняет `otherwise`, если ветвь есть. |
| `repeat while условие … end` | Проверяет условие перед каждой итерацией. Пока результат истинен, выполняет тело и проверяет условие заново. Ложный результат при первой проверке даёт ноль итераций. |
| `for имя in range(граница) … end` | Вычисляет границу один раз перед созданием локальной переменной цикла. Перед каждой итерацией записывает в эту переменную очередное число от нуля до границы без её включения и выполняет тело. При границе `0` или меньше итераций нет. |

Условия `when` и `repeat while` требуют логического значения. Например, условием может быть сравнение `n < 3` или имя переменной, в которой хранится результат сравнения. Число или строка в условии вызывают ошибку выполнения. Парсер проверяет синтаксис всех ветвей и тел до запуска программы. Исполнитель обходит только выбранную ветвь или тело очередной итерации.

Граница `range` должна вычисляться в конечное целое число от `−2^53` до `2^53` включительно. Имя счётчика доступно внутри цикла и затеняет одноимённую внешнюю переменную. Вложенный `for` может объявить собственный счётчик с тем же именем. После его `end` снова доступно внешнее значение, если оно существовало. Присваивание через `remember` обновляет ближайший видимый счётчик с таким именем. Изменение счётчика внутри тела не меняет последовательность следующих итераций.

Вне функции остальные переменные хранятся в общей таблице текущего запуска. `remember` внутри блока обновляет существующее имя или создаёт новое. Изменения в общей таблице видны при следующей проверке условия и после выхода из блока. Если имя создаётся только в пропущенной ветви или в теле цикла с нулём итераций, обращение к нему даёт ошибку неизвестной переменной.

После `remember x = 2` инструкция `remember x = x + 3` читает прежнее значение `x` и сохраняет `5.0`. Если вместо неё выполнить `remember x = 1 / 0`, ошибка возникнет до изменения `x`, и программа остановится.

При ошибке в правой части присваивания сохраняются изменения, уже сделанные при вычислении её подвыражений. Например, `x += y++ / 0` увеличит `y` перед ошибкой деления на ноль, а запись суммы в `x` выполнялась бы только после успешного вычисления.

## Функции

Объявление регистрирует имя функции с момента выполнения этой строки. Повторное объявление даёт ошибку. При вызове исполнитель проверяет имя и число аргументов, затем вычисляет аргументы слева направо в окружении вызывающего кода. Функция может вызывать себя и другие функции, уже зарегистрированные к моменту вызова. Допускается до 128 одновременно активных вызовов.

Каждый вызов создаёт кадр с параметрами. Поиск переменной внутри функции идёт от счётчиков её активных циклов к параметрам и локальным переменным кадра, затем к глобальным переменным. `remember` и числовые операции записи обновляют ближайший счётчик с этим именем либо пишут в текущий кадр. При выходе из вызова кадр уничтожается.

Короткая форма вычисляет выражение сразу. Многострочная форма выполняет тело по порядку, затем вычисляет выражение из строки `return` в том же кадре. Полученное число, логическое значение или строка становится значением вызова. При ошибке в теле вычисление результата пропускается, уже записанный вывод сохраняется.

```minilang
function factorial(n) ->
  remember result = 1
  when n > 1
    remember result = n * factorial(n - 1)
  end
  return result
end

print factorial(5)
```

Каждый рекурсивный вызов получает собственные `n` и `result`. Программа выводит `120.0`.

## Ошибки

| Этап | Условия и примеры | Последствие |
|---|---|---|
| Лексический анализ | Недопустимый байт, неверная запись дроби или незакрытая строка. Например, `print 1.` или `print "a` до конца строки. | Файл не выполняется. |
| Синтаксический анализ | Неизвестная или неполная инструкция, ошибка в выражении, лишний токен после инструкции или нарушенные границы блока. Например, `print 1 +`, незакрытый `when`, повторный `otherwise` в одной конструкции или `repeat` без `while`. | Файл не выполняется, даже если ошибке предшествуют корректные инструкции. |
| Выполнение | Неизвестная переменная, число вне диапазона, неподходящий тип операнда или условия, деление на ноль или сбой записи. Например, `print missing`, `print 1 / 0` или `when 1` с корректно закрытым телом. | Выполнение останавливается. Уже записанный вывод сохраняется. |

CLI сообщает этап и причину ошибки через стандартный поток ошибок. Координаты строки и столбца пока отсутствуют.

## Контрольная программа

```minilang
remember x = 10
remember y = (x + 2) * 3
print y
print y >= 30
remember x = y / 2
print x
```

Ожидаемый вывод:

```text
36.0
true
18.0
```

Пример с вложенным ветвлением и обновлением общей переменной в цикле `repeat while`.

```minilang
remember n = 0
repeat while n < 3
  when n == 1
    print "середина"
  otherwise
    print n
  end
  remember n = n + 1
end
print n
```

Ожидаемый вывод.

```text
0.0
середина
2.0
3.0
```

Эти программы и граничные случаи проверяются в [тестах интерпретатора](../tests/) и [сквозных проверках CLI](../tests/CliTests.cmake).
