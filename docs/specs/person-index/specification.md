# Спецификация персонального индекса

## Назначение

`PersonIndex` хранит записи о людях и поддерживает точный поиск по составному атрибуту и поиск по диапазону годов рождения.

Задание И-5: 7 баллов, И-5.1 — диапазон (+5), И-5.2 — составные атрибуты (+7). Всего за задачу 19 баллов без рейтинга методов поиска.

## Данные и внутреннее состояние

`PersonRecord` содержит `int id`, `std::string firstName`, `std::string lastName`, `int birthYear`.

| Индекс | Ключ | Значение |
|---|---|---|
| `compositeIndex` | `std::tuple<имя, фамилия, год>` | `Array<PersonRecord>` |
| `birthYearIndex` | Год рождения | `Array<PersonRecord>` |

Оба индекса используют `Map` на красно-чёрном дереве. Записи копируются в оба индекса. Исходный объект после добавления можно менять независимо.

Ключи дерева уникальны, но в значении хранится группа записей с одинаковым ключом. Повторное добавление той же записи добавляет ещё одну копию. Уникальность `id`, допустимость года и непустые имена не проверяются.

## Операции

| Метод | Результат |
|---|---|
| `add(person)` | Добавляет запись сначала в составной индекс, затем в индекс года |
| `findComposite(firstName, lastName, birthYear)` | Возвращает копии всех записей с точным совпадением трёх полей |
| `findBirthYearRange(firstYear, lastYear)` | Возвращает копии записей с годом из `[firstYear, lastYear]` |
| `all()` | Возвращает копии всех записей из индекса года |

Результат диапазона и `all()` упорядочен по возрастанию года; внутри одного года сохраняется порядок добавления. В точном поиске также сохраняется порядок добавления в соответствующую группу.

Сравнение строк чувствительно к регистру и выполняется по правилам `std::string`, без нормализации. Составной ключ сравнивается лексикографически: имя, затем фамилия, затем год.

## Ошибки и гарантии

- Поиск отсутствующего ключа и поиск в пустом индексе возвращают пустой массив.
- `firstYear > lastYear` вызывает `std::invalid_argument`, в том числе на пустом индексе.
- Равные границы допустимы и означают поиск одного года.
- Ошибки выделения памяти и копирования передаются вызывающему коду.
- `add` не является транзакцией: сбой после изменения первого индекса может оставить два индекса несогласованными. Откат не реализован.
- Удаление, обновление записей, поиск по `id` и поиск по части составного ключа отсутствуют.

Возвращаемые массивы самостоятельны: изменение результата не изменяет индекс. Константные методы поиска не изменяют хранимые записи.

## Сложность

Пусть `n` — число записей, `c` — число разных составных ключей, `y` — число разных годов, `r` — число найденных записей, `k` — число найденных годов. Сравнение и копирование одной записи считаются постоянными; добавление в массив — амортизированным.

| Операция | Время |
|---|---|
| `add` | Амортизированно `O(log(c + 1) + log(y + 1))`; отдельное расширение группы может быть линейным по её размеру |
| `findComposite` | `O(log(c + 1) + r)` |
| `findBirthYearRange` | `O(log(y + 1) + k + r)` |
| `all` | `O(y + n)` |

Память индексов — `O(n + c + y)` с двумя копиями каждой записи. Строки имеют переменную длину; их сравнение и копирование добавляют соответствующую стоимость. Диапазон сначала получает копии групп через `Map::range`, затем копирует записи в итоговый массив.

Он проверяет группу одинаковых составных ключей, отсутствие точного совпадения, диапазон и обратные границы. Для полной проверки нужны пустой индекс, попадание на обе границы, одинаковые границы, порядок `all()`, повторные `id` и независимость возвращённых копий.
